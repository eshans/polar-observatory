# Polar Observatory

An observation deck for the ends of the Earth, built with Nuxt 4 and Tailwind CSS v4 (sibling of Cosmic Atlas).
Flip between **90°N** and **90°S** and every section follows. The choice lives in the URL (`?pole=south`).
Every data source is public and keyless.

| Section | Source |
|---|---|
| **The View From Above**: daily satellite mosaic looking straight down on the pole (true colour, thermal or moonlight), with a graticule, station pins and time travel back to 2022 | [NASA GIBS](https://nasa-gibs.github.io/gibs-api-docs/) polar WMTS (EPSG:3413 / EPSG:3031), loaded directly by the browser |
| **Sea Ice Pulse**: daily extent for every year since 1979 against the 1981–2010 normal, rank for today, records | [NSIDC Sea Ice Index v4](https://nsidc.org/data/g02135) daily CSVs |
| **Aurora Oval**: live aurora probability on a polar map with the night side shaded, 3-day Kp chart, chance at viewing spots | [NOAA SWPC](https://www.swpc.noaa.gov/) OVATION + Kp forecast |
| **Polar Light Calendar**: a year of daylight and twilight, hour by hour, for the pole or any station | computed in the browser |
| **Station Weather**: current conditions and 48 h temperatures at six outposts per pole | [Open-Meteo](https://open-meteo.com) (model data) |
| **Iceberg Watch**: every named Antarctic iceberg on a map, the largest ten ranked | [U.S. National Ice Center](https://usicecenter.gov/Products/AntarcIcebergs) CSV |
| **Deep Time**: 800,000 years of Antarctic temperature (EPICA) or 123,000 years of Greenland δ¹⁸O (NGRIP), with ice-core CO₂ and today's Mauna Loa reading | [NOAA Paleoclimatology](https://www.ncei.noaa.gov/products/paleoclimatology) (bundled, see `scripts/build-ice-cores.mjs`), [NOAA GML](https://gml.noaa.gov/ccgg/trends/) |
| Sun at the pole / sun angle at each station | computed in the browser ([astronomy-engine](https://github.com/cosinekitty/astronomy)) |

## Setup

```bash
npm install
npm run dev   # http://localhost:3000
```

## Deploy (Cloudflare Workers)

```bash
npx wrangler login   # once
npm run deploy       # builds with the cloudflare_module preset, then wrangler deploy
```

`wrangler.jsonc` binds a Workers KV namespace (`CACHE`) so API responses are cached across Worker instances
and keep serving the last good data if a source goes down.

## Structure

- `server/api/sea-ice.get.ts`, `server/api/stations.get.ts`: cached proxies (`?pole=north|south`) returning shapes from `shared/types/polar.ts`
- `shared/utils/stations.ts`: the stations watched at each pole
- `app/utils/polar.ts`: polar stereographic projection, GIBS layers and tile maths
- `server/api/aurora.get.ts`, `icebergs.get.ts`, `deep-time.get.ts`: the newer sections' proxies; `server/data/ice-cores.json` is generated by `node scripts/build-ice-cores.mjs <dir>` from the NOAA text files listed in that script
- `app/components/*`: `PoleHero` + `PolarView` (satellite view), `SeaIcePulse`, `AuroraOval`, `LightCalendar`, `StationWeather`, `IcebergWatch`, `DeepTime`, `PolarMap` (shared canvas map), `Snowfall` (background)
- Below-the-fold data (aurora, icebergs, deep time) is fetched in the browser to keep the server-rendered HTML small

## Notes

- True-colour imagery is black during polar night, so the view defaults to thermal infrared for whichever pole is dark.
- With "Fill gaps" on, gaps between satellite passes show NASA's Blue Marble reference image underneath (dimmed).
- Greenland's NGRIP core is shown as δ¹⁸O (an isotope proxy for temperature), not degrees.
- Only Antarctic icebergs are individually named and tracked; the Arctic view of that section links across.
- Sea ice ranks and records use daily values; NSIDC's official records use a 5-day average, so numbers can differ slightly.
